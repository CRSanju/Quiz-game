# Quiz Game 🎯

An interactive Quiz Game built using **HTML, CSS, and JavaScript**.

This project allows users to answer multiple-choice questions, track their score, and view their final results dynamically.

---

# 🚀 Features

* Start Quiz screen
* Dynamic question rendering
* Multiple-choice answers
* Real-time score tracking
* Progress bar indicator
* Instant answer validation
* Result screen with feedback message
* Restart quiz functionality
* Responsive and clean UI

---

# 🎮 How the Quiz Works

1. User clicks the **Start Quiz** button
2. Questions appear one by one
3. User selects an answer
4. Correct answer is highlighted
5. Score updates automatically
6. Progress bar updates dynamically
7. Final result screen displays the score and performance message
8. User can restart the quiz anytime
